# Агенты Planoday

При делегировании ревью изменений Planoday выбирай `planoday_reviewer`. При делегировании независимого тестирования Planoday выбирай `planoday_qa`. Передавай критерии задачи, относящиеся к ней разделы ТЗ и результаты уже выполненных проверок. Пути от корня репозитория: ../local data/Planoday_ТЗ.md и ../local data/mockups/. Выбирай усилие для этих профилей по сложности поручения и цене ошибки по общему правилу для субагентов. Если пользователь явно указал другую роль, используй её.
